# ITIFinialProject

CenterApp, an ASP.NET Core 6 MVC graduation project from ITI.

## Solution layout

- `CenterAppWeb`: the MVC web application (controllers, views, view models)
- `CenterApp.Core`: domain models
- `CenterApp.Infrasturcture`: data access (`CenterDBContext`) and EF Core migrations
